The original markdown documents behind this site, captured verbatim under briefs/ and readable here. Each page carries the same apparatus — a summary, the key concepts (linked to where they live on the site), the key ideas, a slot for the matching infographic — and then the full document, rendered in-page from the raw markdown. The raw file stays the source of truth; the page is presentation. That raw-plus-curated split is itself the provenance discipline the shared-drives brief argues for.
