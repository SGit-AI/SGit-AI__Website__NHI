PKI: the cryptographic half of the identity gap

This work now has its own site: pki.sgit.ai — the public key infrastructure for agents, designed in public from a documented failure. It was staged here first (this site is where the need is established); with the spin-out live, this page is the bridge. The NHI angle is unchanged: the shared-drives research found that no available system gives an agent its own identity, agent-level attribution, or encryption to a specific agent — per-agent keys in a registry are what would fill those empty rows.
